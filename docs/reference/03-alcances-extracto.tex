El proyecto comprende el análisis de toda la empresa, su diseño
conceptual global y, para el módulo priorizado, el diseño lógico, el
diseño físico y un prototipo funcional con tablas, restricciones,
consultas e informes. Los demás módulos conservan su análisis y su diseño
conceptual (anexos~\ref{anx:analisis} y~\ref{anx:global}) para
implementarse después. No se desarrollan las aplicaciones de los
usuarios (aplicación del mensajero, portal de consulta); la base de
datos queda lista para que se conecten.
